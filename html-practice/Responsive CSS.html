Q9. Responsive Design Principles Summary

Fluid Layouts

Widths use percentages or fr units instead of fixed pixels.

.container {
  width: 90%;
  display: grid;
  grid-template-columns: 1fr 2fr;
}

Flexible Media

Images and videos scale within their containers.

img {
  max-width: 100%;
  height: auto;
}

Breakpoints

Media queries change the layout at specific widths.

@media (max-width: 600px) {
  .container { display: block; }
}
